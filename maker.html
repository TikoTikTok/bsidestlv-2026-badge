Build a room for Alice

Every stage in this game is a few lines of text: a walled room, some rocks, the buttons they belong on, a lever, a gate, a door. The level maker is a page in this repository that draws it with the game's own art, proves it can be solved, and lets you play it from the keyboard the way the badge would. Make one. Send it in. It ships with the next deploy.

…or by hand

The maker runs from a clone of the repository on your own machine, where the keyboard is allowed to play. This page is only the invitation; the published site plays from the badge alone.

You are on a local checkout: the maker is below. WASD or the arrows move, Z X C V are A B X Y, Q E the shoulders, Enter is START and Backspace SELECT. A badge on USB works too.

How it goes

  1. Clone the repository. Node 20 or newer is all it needs: no packages, no build. npm run maker serves the checkout and opens the maker in your browser.
  2. Draw, check, play. Paint walls and rocks on the grid, or type the map. Check runs the real solver and says how many moves the room takes, and whether the gate earns its keep. Run & debug plays it with a simulated badge, every press logged.
  3. Send it in. Export writes a stage module, stages/community/<id>.js. Add it to the index, open a pull request; the checks prove it is solvable before anyone has to play it.

What a stage is

// Stage: "A Small Garden"
//
//   #  wall     .  floor    A  Alice    O  rock
//   b  button   L  lever    G  gate     D  door

export const A_SMALL_GARDEN = {
  name: 'A Small Garden',
  theme: 'garden',
  rows: [
    '#########',
    '#A..#..b#',
    '#.O.G...#',
    '#...#...#',
    '#.L.#..D#',
    '#########',
  ],
};

Push every rock onto a button and walk Alice to the door. A gate stays shut until she steps on the lever. A rock pushed into a corner is lost, so the order of the shoves is the puzzle. Nothing is scripted: the page proves a room with the same search the site is deployed with, and a room that cannot be solved is refused.

A timed room adds a clock and a cast: tickMs: 320 and a list of hazards, each walking a loop one cell per tick. The Red Queen also looks ahead, so a straight line of open floor between her and Alice ends the run. Then a plan is a schedule, and standing still is a move.

Three dressings: garden, hall, court. Rooms are between 4×4 and 24×24, walled all round.

By hand

git clone https://github.com/bsidestlv/bsidestlv-2026-badge.git
cd bsidestlv-2026-badge
npm run maker                                   # serves http://localhost:8080 and opens maker.html
npm run stage -- stages/community/my-room.js    # what CI will say about it

The whole guide, with the format, the rules the checker applies and how a room gets onto the site: software/docs/LEVEL_MAKER.md.

The room

Click or drag to paint with the brush; right-click paints floor. Alice and the door are single, so painting one moves it. With a hazard selected, clicks lay its route instead, point by point, straight lines only; the loop closes itself. Ctrl+Z takes an edit back.
