The range

Three practice ranges for the badge's quick glitch layer. Plug the badge in and press anything — the header lights up when the browser sees it. The published site listens to the badge and nothing else; on a local checkout the keyboard stands in: arrows, Z X C V for A B X Y, Q E for the shoulders, Enter for START.

Only the armed range listens. Click a range to arm it. The first level of each is meant for a hand; the last is not, and that is the lesson.

Range 1 — The Rabbit's Pocket Watch ● armed

how it works

The Rabbit chimes a tune of buttons. Play it back, in order, inside the window — measured from your first press to your last. A wrong button or a slow finish ends the attempt; the next press starts a fresh one. The tune is fixed per level, so a take recorded once on the badge keeps working: record it slowly, then SELECT+UP until it fits.

    Range 2 — The Looking-Glass Glitch ● armed

    how it works

    The Queen's guard runs a routine at the treasure room door, one line per tick. One of those lines is the check that turns Alice away. A pulse on X whose rising edge lands while that line executes skips it — the routine falls through, the door opens, and Alice jumps to the treasure. START is the trigger: the routine starts the instant the browser sees it. Land anywhere else and the log says where you hit and by how much.

    A pulse is measured from its rising edge to its falling edge. Every line under it is corrupted, some lines crash the guard, and a pulse wider than the guard survives browns it out. Width is the badge's speed; offset is SELECT+LEFT/RIGHT.

        Range 3 — The Caterpillar's Lock ● armed

        how it works

        The Caterpillar's door wants a password and checks it the lazy way: one symbol per tick, in order, stopping at the first one that is wrong. So the time it takes to say no is the number of symbols you had right, plus one — a side channel. START opens a guess, then one press per symbol; the door checks the moment the last one is in. Read the clock, change one symbol, go again.

        On the badge a guess is a take: record the symbols only (no START), then fire — the trigger's START opens the guess and the take types it. Give the take an offset of 40 ms or so (SELECT+RIGHT) so START lands first. Hold the chord and the same guess goes in every ~600 ms, which is how the jittery levels are beaten: the readout keeps the median.

            Using the badge

            SELECT is the shift key. While it is held nothing you press reaches the browser, and every other button is a command. A plain SELECT still arrives as a tap when you let go.

            SELECT + SLrecord a take; again to stop. Silence before and after is trimmed.
            SELECT + SRfire: tap START, wait the offset, replay the take at the speed. Hold the chord to fire again every ~600 ms.
            SELECT + UP / DOWNspeed ×2 / ÷2, from 1/4× to 32×. Scales gaps and hold times alike.
            SELECT + LEFT / RIGHToffset −/+ 1 ms; hold to repeat, and the step grows to 10 ms after twenty.
            SELECT + Bforget the take, offset 0, speed 1×.
            SELECT + Y, heldthe beacon: the badge spells its vault — serial and stage key — on the stick axes, for browsers without WebHID. The gate on these pages reads it; the vault page shows it.
            SELECT + START, held 2 sreboot into the UF2 bootloader (the RPI-RP2 drive) to take a new firmware — the flash page writes one from this browser, software/tools/flash-badge.py from a checkout.

            Range 1: record the tune at a comfortable pace, stop, then fire. Too slow? SELECT+UP and fire again. Too fast and the browser starts dropping presses — it samples the pad every ~16 ms, so a press needs to be held about 20 ms to be seen. The log shows the rate you achieved and the gap between each press.

            Range 2: record a single X tap, stop. Read the target's tick off the listing, multiply by the tick length, add half a tick: that is the offset. SELECT+RIGHT until the log's offset readout says so, then fire. Nudge and fire again; or hold the chord and tap RIGHT between shots to sweep. SELECT+UP shortens the pulse if it is crashing on the line after the check.

            Range 3: record the guess's symbols only, set an offset of ~40 ms so the trigger's START lands before the first symbol, fire. The log says how many ticks the door took; one more tick than last time means the symbol you changed is right. When the level jitters, hold the chord: every ~600 ms the same guess goes in and the readout keeps the median. One symbol per take, and a level with a secret order gives up which position it checks next the same way.
